# Security policy

## Supported versions

Security fixes are considered for the current default branch. No tagged releases or historical commits are currently supported.

Club Operations System is a local reference system, not a hosted production service. This policy covers vulnerabilities in the repository's code, configuration, and documentation. It does not represent a production support or incident-response service-level agreement.

## Report a vulnerability

When the repository's **Security** tab displays **Report a vulnerability**, use that form to submit the report privately. If the private form is not available, do not open a public issue or disclose the vulnerability in a discussion.

Include:

- the affected commit, file, route, or component;
- the expected and observed behavior;
- minimal reproduction steps or a proof of concept;
- the potential impact and any suggested mitigation; and
- redacted logs or screenshots when they help explain the report.

Do not include credentials, secrets, or real personal data. Do not test against systems or data you do not own or have permission to use.

This repository does not publish a security-reporting email address and does not provide a production service-level agreement.
